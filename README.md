# REF-01 // Audio Quality Inspector & Acoustic Field Analyzer

**REF-01** — браузерный аналитический DSP-инструмент профессионального уровня для диджеев, мастеринг-инженеров и аудиофилов. Приложение позволяет детально исследовать спектральную чистоту аудиозаписей, выявлять поддельные (апскейленные) lossless-файлы («транскоды»), контролировать фазовую корреляцию стереополя и визуализировать акустическую энергию в реальном времени при стабильных 60 FPS.

Интерфейс выполнен в строгой индустриальной эстетике (Braun / Teenage Engineering / FabFilter) без лишней графики: 1px сетка, палитра `#0A0A0A` / `#EDEDED` / `#FF4D00` и моноширинные числовые шкалы на базе *JetBrains Mono*.

---

## 🎯 Назначение

- **Проверка подлинности Hi-Res и Lossless аудио**: выявление MP3/AAC-файлов, пересохраненных в WAV/FLAC («fake flac» / транскоды со срезанными высокими частотами).
- **Спектральный и фазовый мониторинг**: прецизионный логарифмический спектроанализатор с водопадом (spectrogram) и гониометр (Lissajous) для контроля моносовместимости и стереобазы.
- **Инспекция громкости и динамики**: раздельный пиковый и RMS-мониторинг, детекция клиппинга (True Peak / Clip Latch) и оценка громкости по стандарту ITU-R BS.1770 (LUFS Momentary, Short-Term, Integrated + PLR).

---

## ⚙️ Как это работает

Приложение построено на базе **Web Audio API** и **Three.js** с обработкой на чистом клиенте без передачи аудио на внешние серверы:

1. **Маршрутизация DSP**: аудиопоток (из загруженного локального файла или встроенного процедурного синтезатора) поступает на общую шину `masterInputGain` ➔ каскад симулятора транскода ➔ анализаторы высокого разрешения.
2. **Анализ FFT (8192 точки)**:
   - Отслеживает как мгновенный спад спектра (`Live Cutoff`), так и максимальный пиковый потолок (`Peak Ceiling`), сохраняемый в буфере `maxSpectrumHold` выше порога **−78 dBFS** (что исключает ложные срабатывания на тихих интро/аутро).
   - Классифицирует запись:
     - 🟢 **VERIFIED LOSSLESS** (≥ 19.4 кГц) — полноценный несжатый спектр.
     - 🟡 **LOSSY STREAM** (16.3 – 19.3 кГц) — компрессия уровня MP3 192–320 kbps.
     - 🔴 **TRANSCODE ALERT** (≤ 16.2 кГц) — кирпичный срез частот (характерно для 128 kbps).
3. **Симулятор транскода (16 kHz Brickwall Simulator)**:
   - В реальном времени переключает каскад крутых фильтров низких частот на 15.8 кГц, позволяя мгновенно сравнить звучание оригинала и искусственно сжатого сигнала, а также проверить реакцию всех графиков.
4. **Собственный парсер заголовков и декодер PCM**:
   - Читает форматы WAV/RF64, AIFF/AIFF-C (включая Big-Endian PCM, не поддерживаемый напрямую движком Chromium), FLAC, MP3 (с тегами Xing/VBRI), OGG и MP4/M4A.

## 🎛 Модули приложения

- **Top Bar & Scrubber**: транспорт (Play/Pause, Stop, Loop), точный таймлайн с миллисекундами, переключатель симулятора транскода и технический паспорт файла (контейнер, кодек, битрейт, частота дискретизации, разрядность).
- **Module 01 // Transcode & Cutoff Radar**: статус-бейдж подлинности, график динамики частотного среза и детальные метрики (Peak Ceiling, Live Cutoff, Spectral Centroid, Dynamic Crest, HF Energy Ratio >16k).
- **Module 01B // HF Shelf Microscope**: масштабированная линейная область 10–22 кГц для детального изучения крутизны спада полосы частот.
- **Module 02A // 2D FFT Precision Spectrum + Waterfall**: логарифмический спектр 20 Гц – 22 кГц с пиковым следом, интерактивным курсором (нота, частота, уровень dB) и термальным скроллирующимся спектрографом.
- **Module 02B // 3D Ferrofluid Acoustic Field**: трехмерное ядро из темного жидкого хрома с раздельной многополосной деформацией вершин (Sub/Kick 20–120 Гц, Mids 120–4000 Гц, Highs 8–22 кГц). При наличии частот выше 16 кГц поверхность покрывается микрошипами; при транскоде шипы мгновенно сглаживаются.
- **Module 04 // Lissajous Goniometer (Phase Scope)**: фазовый скоп с фосфорным послесвечением, шкала фазовой корреляции Пирсона (-1.0...+1.0) и процент стереоширины.
- **Module 05 // Dual-Channel Peak & RMS Meters**: поканальные индикаторы L/R (-60...0 dBFS), защелкивающиеся индикаторы перегрузки `[CLIP]`, расчет LUFS и PLR (Peak-to-Loudness Ratio).
- **Internal Reference Synth Loop**: автономный генератор тестового лупа (124 BPM) с саб-басом 55 Гц, стерео-аккордами и белым шумом до 22 кГц для тестирования без внешних файлов.

## 🚀 Запуск и сборка

Требуется установленный **Node.js** (версии 18+).

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Проверка типов и сборка в production
npm run build

# Предпросмотр production-сборки
npm run preview
```

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Space` | Воспроизведение / Пауза (или запуск тест-синтезатора) |
| `Esc` | Остановка и возврат воспроизведения в начало |
| `T` | Переключение симулятора транскода 16 кГц (ON / OFF) |
| `V` | Переключение режима видоискателя (2D FFT Spectrum ↔ 3D Ferrofluid) |
| `G` | Включение / выключение тестового генератора (Synth Loop) |
| `R` | Сброс пиковых значений (Peak-Hold, Clip, Radar Ceiling) |
| `L` | Зацикливание воспроизведения (Loop) |
| `Drag & Drop` | Перетащите любой аудиофайл в окно браузера для мгновенного анализа |
